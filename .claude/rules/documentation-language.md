# Langue de la documentation

**Quand :** tout Markdown du repo (`README.md`, `CLAUDE.md`, `docs/`,
`.claude/`, `.ai/`).

- Rédiger en **français**.
- Laisser inchangés : identifiants de code, commandes CLI, chemins,
  noms de packages.
- Markdown concis, liens relatifs qui marchent.
- Source anglaise : traduire le récit, garder les identifiants techniques.
- Le code suit sa propre règle (`CLAUDE.md` § Conventions de code) : UI
  en français, cœur technique en anglais.
